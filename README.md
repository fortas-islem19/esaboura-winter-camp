# مخيم المهارات 03 — مدرسة السبورة، سطيف

صفحة هبوط (Landing Page) للتسجيل في **مخيم المهارات 03** (الطبعة الشتوية، ديسمبر 2026):

| الدورة | الموعد | التأطير |
|---|---|---|
| الكتابة الأكاديمية والنشر الدولي في المجلات المرموقة: دليل عملي تطبيقي | 17 – 18 ديسمبر | الدكتور عبد الحق لفيلف |
| علم البيانات | 19 – 24 ديسمبر | الدكتور زيراري، الدكتور أيمن بنيحي |
| تحليل البيانات باستخدام SPSS | يُعلن لاحقًا | البروفيسور يعلى |

موقع ثابت (HTML + CSS + JS) بلا أي خطوة بناء: يكفي رفع الملفات كما هي إلى أي استضافة.

## الملفات

```
index.html            الصفحة
assets/css/style.css  التصميم
assets/js/config.js   ← الإعدادات (الملف الوحيد الذي تحتاج تعديله)
assets/js/main.js     سلوك الصفحة والاستمارة والبيكسل
assets/img/           الأيقونة وصورة المعاينة (og-image.jpg)
```

## الإعدادات (`assets/js/config.js`)

| المفتاح | الوظيفة |
|---|---|
| `metaPixelId` | معرّف بيكسل ميتا (أرقام فقط). يبقى البيكسل معطّلاً حتى تضعه. |
| `formEndpoint` | رابط FormBold: `https://formbold.com/s/6QjEX` |
| `campStart` | تاريخ انطلاق المخيم للعدّاد التنازلي (يختفي العدّاد بعده تلقائيًا). |
| `spssDate` | موعد دورة SPSS. فارغ = «يُعلن الموعد قريبًا» في كل مكان. |
| `prices` | رسوم كل دورة وباقة المخيم كاملاً بالدينار. الفارغ لا يظهر. |
| `contact` | الهاتف، واتساب (بصيغة `213…`)، البريد، فيسبوك، إنستغرام، العنوان، رابط الخريطة. الفارغ يُخفى. عند ضبط واتساب يظهر زر عائم وزر «أكّد عبر واتساب» بعد التسجيل. |

## الاستمارة ← FormBold

ترسل الاستمارة عبر `fetch` إلى FormBold وتعرض رسالة النجاح داخل الصفحة دون مغادرتها.
الحقول التي تصل إلى بريدك في FormBold:

`full_name`، `phone` (بعد توحيد صيغته)، `email`، `wilaya`، `status`، `specialty`،
`courses` (الدورات المختارة في سطر واحد)، `notes`، `form_name`، `submission_id`،
`submitted_at` (بتوقيت الجزائر)، `page_url`، `utm_source`، `utm_medium`، `utm_campaign`،
`utm_content`، `utm_term`، `fbclid`.

- التحقق من الحقول يتم بالعربية قبل الإرسال (الاسم، رقم هاتف جزائري أو دولي، الولاية، الصفة، دورة واحدة على الأقل).
- أزرار «سجّل في هذه الدورة» تختار الدورة مسبقًا في الاستمارة.
- حقل مخفي (honeypot) يصدّ الرسائل الآلية.
- `submission_id` يسمح بكشف أي إرسال مكرّر.
- إن كان جافاسكربت معطّلاً، تُرسل الاستمارة مباشرة إلى FormBold.

> **بعد النشر:** أرسل استمارة تجريبية واحدة وتأكّد من وصولها إلى لوحة FormBold.

## بيكسل ميتا: الأحداث المُرسلة

| الحدث | متى |
|---|---|
| `PageView` | عند فتح الصفحة |
| `ViewContent` | عند الوصول إلى قسم البرنامج |
| `FormStart` (مخصّص) | أول نقرة داخل الاستمارة |
| `Lead` | بعد نجاح الإرسال (مع أسماء الدورات، والقيمة بالدينار إن ضُبطت الأسعار) |
| `Contact` | النقر على الهاتف أو واتساب |

استعمل حدث **Lead** هدفًا للتحويل في حملاتك الإعلانية.
تُلتقط وسوم `utm_*` و`fbclid` من رابط الإعلان وتُرسل مع كل تسجيل.

## النشر

ارفع محتوى المجلد كما هو إلى أي استضافة ثابتة (Netlify، Vercel، GitHub Pages، Cloudflare Pages، أو استضافة cPanel).
بعدها:

1. ضع معرّف البيكسل ومعلومات التواصل في `assets/js/config.js`.
2. في `index.html` استبدل قيمة `og:image` برابط كامل للصورة، مثال: `https://example.com/assets/img/og-image.jpg`، لتظهر المعاينة عند مشاركة الرابط على فيسبوك وواتساب.
3. لإضافة صور المؤطّرين: ضعها في `assets/img/trainers/` واتّبع التعليق في قسم «المؤطّرون» داخل `index.html`.
