# مخيم المهارات 03 — مدرسة السبورة، سطيف

صفحة هبوط (Landing Page) للتسجيل في **مخيم المهارات 03** (الطبعة الشتوية، ديسمبر 2026):

| الدورة | الموعد | التأطير |
|---|---|---|
| الكتابة الأكاديمية والنشر الدولي في المجلات المرموقة: دليل عملي تطبيقي | 17 – 18 ديسمبر | الدكتور عبد الحق لفيلف |
| علم البيانات | 19 – 24 ديسمبر | الدكتور زيراري، الدكتور أيمن بنيحي |
| تحليل البيانات باستخدام SPSS | يُعلن لاحقًا | البروفيسور فاروق يعلى |

موقع ثابت (HTML + CSS + JS) بلا أي خطوة بناء، مع دالة خادم واحدة على **Vercel** لإرسال الأحداث عبر Meta Conversions API.

## الملفات

```
index.html            الصفحة
assets/css/style.css  التصميم
assets/js/config.js   ← الإعدادات (الملف الوحيد الذي تحتاج تعديله)
assets/js/main.js     سلوك الصفحة والاستمارة والبيكسل
assets/img/           شعار السبورة (بنفسجي وأبيض)، الأيقونات، صورة المعاينة (og-image.jpg)
assets/img/trainers/  صور المؤطّرين (مربّعة 320×320)
api/capi.js           دالة Vercel لإرسال الأحداث إلى Meta Conversions API
```

## الإعدادات (`assets/js/config.js`)

| المفتاح | الوظيفة |
|---|---|
| `metaPixelId` | معرّف بيكسل ميتا: `1084066284668146` |
| `capiEndpoint` | مسار دالة Conversions API: `/api/capi` (فارغ = تعطيل الإرسال من الخادم) |
| `formEndpoint` | رابط FormBold: `https://formbold.com/s/6QjEX` |
| `campStart` | تاريخ انطلاق المخيم للعدّاد التنازلي (يختفي العدّاد بعده تلقائيًا). |
| `spssDate` | موعد دورة SPSS. فارغ = «يُعلن الموعد قريبًا» في كل مكان. |
| `prices` | رسوم كل دورة وباقة المخيم كاملاً بالدينار. الفارغ لا يظهر. |
| `contact` | الهاتف، واتساب (بصيغة `213…`)، البريد، فيسبوك، إنستغرام، العنوان، رابط الخريطة. الفارغ يُخفى. عند ضبط واتساب يظهر زر عائم وزر «أكّد عبر واتساب» بعد التسجيل. |

## الاستمارة ← FormBold

ترسل الاستمارة عبر `fetch` إلى FormBold وتعرض رسالة النجاح داخل الصفحة دون مغادرتها.
الحقول التي تصل إلى بريدك في FormBold:

`full_name`، `phone` (بعد توحيد صيغته)، `email`، `wilaya`، `status`، `specialty`،
`courses` (الدورات المختارة في سطر واحد)، `notes`، `form_name`، `submission_id`،
`submitted_at` (بتوقيت الجزائر)، `page_url`، `utm_source`، `utm_medium`، `utm_campaign`،
`utm_content`، `utm_term`، `fbclid`.

- التحقق من الحقول يتم بالعربية قبل الإرسال (الاسم، رقم هاتف جزائري أو دولي، الولاية، الصفة، دورة واحدة على الأقل).
- أزرار «سجّل في هذه الدورة» تختار الدورة مسبقًا في الاستمارة.
- حقل مخفي (honeypot) يصدّ الرسائل الآلية.
- `submission_id` يسمح بكشف أي إرسال مكرّر.
- إن كان جافاسكربت معطّلاً، تُرسل الاستمارة مباشرة إلى FormBold.

> **بعد النشر:** أرسل استمارة تجريبية واحدة وتأكّد من وصولها إلى لوحة FormBold.

## بيكسل ميتا + Conversions API

كل حدث يُرسل مرتين بنفس `event_id`: من المتصفح (البيكسل) ومن الخادم (`/api/capi`).
تحذف ميتا التكرار تلقائيًا، وتصل الأحداث حتى لو حجب الزائر البيكسل بمانع إعلانات.

| الحدث | متى |
|---|---|
| `PageView` | عند فتح الصفحة |
| `ViewContent` | عند الوصول إلى قسم البرنامج |
| `FormStart` (مخصّص) | أول نقرة داخل الاستمارة |
| `Lead` | بعد نجاح الإرسال (مع أسماء الدورات، والقيمة بالدينار إن ضُبطت الأسعار) |
| `Contact` | النقر على الهاتف أو واتساب |

استعمل حدث **Lead** هدفًا للتحويل في حملاتك الإعلانية.
تُلتقط وسوم `utm_*` و`fbclid` من رابط الإعلان وتُرسل مع كل تسجيل.

بيانات المطابقة المُرسلة من الخادم: عنوان IP، المتصفح، `fbp`، `fbc`، معرّف الزائر، والبلد (`dz`).
ومع حدث **Lead**: الهاتف (بصيغة `213…`)، البريد، الاسم واللقب.
كل البيانات الشخصية تُشفَّر بـ SHA-256 في الخادم قبل إرسالها إلى ميتا.

### متغيّرات البيئة على Vercel

| المتغيّر | القيمة |
|---|---|
| `META_ACCESS_TOKEN` | **إجباري.** رمز الوصول من Events Manager ← Settings ← Conversions API. |
| `META_TEST_EVENT_CODE` | اختياري. رمز «Test events» للتجربة، **احذفه بعد التأكد**. |
| `META_PIXEL_ID` | اختياري (افتراضيًا `1084066284668146`). |
| `META_API_VERSION` | اختياري (افتراضيًا `v24.0`). |
| `ALLOWED_HOSTS` | اختياري. نطاقاتك مفصولة بفواصل، مثال: `example.com,www.example.com`. |

> ⚠️ **رمز الوصول سرّي ولا يُكتب في أي ملف داخل المستودع** (المستودع عام).
> مكانه الوحيد: متغيّرات البيئة في Vercel.

## النشر على Vercel

**المشروع منشأ ومنشور:** https://esaboura-winter-camp.vercel.app
(مشروع `esaboura-winter-camp`، مع `META_ACCESS_TOKEN` مضبوط كمتغيّر Sensitive للإنتاج والمعاينة).

> فرع الإنتاج في Vercel هو `main`: كل دفعة إلى `main` تُنشر على الرابط أعلاه،
> وكل دفعة إلى فرع آخر تُنشئ رابط معاينة فقط.

الخطوات أدناه للمرجع إن احتجت إعادة الإعداد من الصفر:

1. في [vercel.com](https://vercel.com): **Add New ← Project** واستورد المستودع `esaboura-winter-camp`.
   اترك Framework Preset على **Other** دون أي أمر بناء.
2. قبل الضغط على Deploy، افتح **Environment Variables** وأضف `META_ACCESS_TOKEN` بقيمة رمز الوصول.
   للتجربة أضف أيضًا `META_TEST_EVENT_CODE` (من Events Manager ← Test events).
3. اضغط **Deploy**. كل دفعة (push) إلى GitHub تُنشر تلقائيًا بعد ذلك.
4. افتح الموقع، وأرسل تسجيلًا تجريبيًا، ثم تأكّد من:
   - وصول التسجيل إلى لوحة FormBold؛
   - ظهور أحداث **Browser** و**Server** معًا في Events Manager ← Test events، مع «Deduplicated».
5. احذف `META_TEST_EVENT_CODE` وأعد النشر (Redeploy).

بعد ذلك:

1. أضف معلومات التواصل والأسعار في `assets/js/config.js`.
2. عند ربط نطاق خاص، استبدل `esaboura-winter-camp.vercel.app` به في `og:url` و`og:image` و`canonical` داخل `index.html`.
3. لتغيير صورة مؤطّر: استبدل ملفه في `assets/img/trainers/` بصورة مربّعة بالاسم نفسه.

**الهوية البصرية:** لون الشعار الرسمي `#8E12DE`، ومتغيّرات الألوان في أعلى `assets/css/style.css`.
